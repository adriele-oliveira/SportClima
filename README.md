# SportClima

O SportClima é uma aplicação web desenvolvida como trabalho da disciplina de Desenvolvimento Web Design, com o objetivo de colocar em prática os conhecimentos adquiridos ao longo das aulas por meio da criação de uma solução web voltada à experiência do usuário.

A proposta do projeto é oferecer uma plataforma de previsão do tempo com foco em esportes ao ar livre, reunindo informações climáticas importantes para auxiliar praticantes no planejamento de suas atividades esportivas de forma mais segura e confortável.

**Deploy do projeto:** https://sportclima.vercel.app/

---

## Sobre o Projeto

O SportClima surgiu da ideia de unir tecnologia e praticidade em uma ferramenta que pudesse ajudar pessoas que realizam atividades físicas ao ar livre e dependem diretamente das condições climáticas para organizar sua rotina.

Durante o desenvolvimento, buscamos criar uma interface que apresentasse os dados meteorológicos de forma clara e objetiva, permitindo que o usuário visualize rapidamente informações relevantes antes de praticar seu esporte.

O sistema foi pensado especialmente para atender modalidades como:

* Corrida
* Surfe
* Ciclismo

Cada uma dessas práticas possui necessidades diferentes em relação ao clima, e por isso o projeto foi estruturado para destacar informações que realmente impactam a experiência do praticante, como temperatura, vento, umidade, índice UV e horários recomendados.

---

## Público-Alvo

O SportClima foi pensado para atender pessoas que praticam esportes ao ar livre e desejam acompanhar as condições climáticas antes de iniciar suas atividades.

Entre os usuários que podem se beneficiar da plataforma, destacam-se:

* Corredores que buscam horários mais agradáveis para treino
* Ciclistas que precisam analisar vento e clima antes de percursos longos
* Surfistas que dependem das condições ambientais para melhor aproveitamento das ondas

Além disso, o sistema também pode ser utilizado por qualquer pessoa que queira planejar atividades físicas externas de forma mais organizada e consciente.

* Estruturação semântica de páginas com HTML5
